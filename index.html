BloxDesk

Plateforme de support & communication Roblox

Bienvenue sur BloxDesk !

Utilise cette plateforme pour envoyer une demande ou un message directement à l'équipe. Sois le plus clair possible dans tes explications.

Guide d'utilisation

  1. Copie ton ID Discord (Clic droit sur ton profil Discord en Mode Développeur).
  2. Indique ton Pseudo Roblox exact.
  3. Écris ton message (jusqu'à 2 000 caractères autorisés).
  4. Envoie et vérifie le message de confirmation vert.
0 / 2000

En envoyant ce formulaire, tes identifiants et ton message sont transmis à l'équipe via Discord.
