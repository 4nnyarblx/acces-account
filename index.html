Bienvenue sur BloxDesk !

Bienvenue sur notre plateforme officielle. Avant de transmettre ton message ou ta demande, assure-toi de bien remplir tes identifiants exacts afin que nous puissions te recontacter si nécessaire.


Choisis une option ci-dessous pour continuer : accède directement au formulaire d'envoi ou consulte notre tutoriel d'aide.

Comment envoyer un message ?

Suis ces étapes simples pour transmettre tes informations à notre équipe :

  1. Clique sur le bouton « Commencer ».
  2. Récupère ton ID Discord (Paramètres Discord > Avancé > Mode développeur > Clic droit sur ton profil > Copier l'identifiant).
  3. Renseigne ton Pseudo Roblox exact.
  4. Rédige ton message dans la grande zone de texte (les longs messages sont supportés).
  5. Clique sur « Envoyer » et attends le message de confirmation vert.
